サポート

Camelotの動作環境と、ヒントが表示されない場合の確認方法をご案内します。

動作環境

  • macOS 26以降
  • AppleシリコンまたはIntel Mac
  • アクセシビリティと入力監視の許可

必要な権限

Camelotが配布された後、macOSの「システム設定」→「プライバシーとセキュリティ」で設定します。

  • アクセシビリティ: 前面ウィンドウの操作対象を調べ、選択された項目を実行するため。
  • 入力監視: Optionキーとヒント文字を検知するため。

権限を変更した後は、Camelotを終了してから再度開いてください。

ヒントが出ないとき

  1. システム設定で、Camelotのアクセシビリティと入力監視が許可されているか確認します。
  2. アプリやパスワード欄などでmacOSの安全な入力制限が有効になっていないか確認します。
  3. 対象アプリがアクセシビリティ情報を公開しているか確認します。対応状況はアプリや画面によって異なります。
  4. 設定を変えた場合はCamelotを終了して再度開きます。

macOSのアクセシビリティ情報を公開していない画面では、ヒントが表示されないことがあります。

更新後に権限を求められた場合

アプリの更新後に権限が外れた場合は、システム設定の該当項目でCamelotを再度許可してください。詳しい配布・インストール手順は、配布開始後にこのページへ掲載します。
